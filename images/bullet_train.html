  1. Data Loading

Problem Context:

We have two separate datasets:

  • one with travel details (Traveldata_train.csv) and another with survey responses (Surveydata_train.csv).
  • We'll merge them on the 'ID' column to form a single training dataset.
  • Similarly, there's a test dataset (travel_data_test & survey_data_test), which we'll merge for predictions.
  • Our target is 'Overall_Experience' (1 => Satisfied, 0 => Not Satisfied).

  1. Data Cleaning

We see some columns may have null values. Instead of dropping rows with missing values, we'll impute them. We'll demonstrate one approach:

  1. For numeric features, we can use a KNNImputer or fill with median.
  2. For categorical features, we fill with mode.

Below, we'll do a simple random fill for demonstration, but a more robust approach is recommended (like KNNImputer). We'll apply the same to test data.

Simple Random Fill Imputation for Demonstration

In [4]:
# For each column, fill nulls with a random selection from existing (non-null) distribution
for column in train_df.columns:
    # Distribution of non-null values in that column
    distribution = train_df[column].value_counts(normalize=True)
    # Number of null values
    num_nulls = train_df[column].isnull().sum()
    if num_nulls > 0:
        # Random choice from existing categories based on distribution
        random_sample = np.random.choice(distribution.index, 
                                         size=num_nulls, 
                                         p=distribution.values)
        # Fill the null values
        train_df.loc[train_df[column].isnull(), column] = random_sample

In [9]:
def evaluate_model_performance(model, X_tr, y_tr, X_val, y_val, model_name="Model"):
    """
    Fits the model on training data, predicts on both train and val,
    and prints classification metrics & confusion matrix.
    """
    model.fit(X_tr, y_tr)
    
    # Predict on training set
    y_tr_pred = model.predict(X_tr)
    # Predict on validation set
    y_val_pred = model.predict(X_val)
    
    print(f"\n--- {model_name} Performance ---")
    print("Training Accuracy:", accuracy_score(y_tr, y_tr_pred))
    print("Validation Accuracy:", accuracy_score(y_val, y_val_pred))
    
    # Classification report on validation set
    print("\nValidation Classification Report:")
    print(classification_report(y_val, y_val_pred))
    
    # Confusion matrix
    cm = confusion_matrix(y_val, y_val_pred)
    plt.figure()
    sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
                xticklabels=["Not Satisfied", "Satisfied"],
                yticklabels=["Not Satisfied", "Satisfied"])
    plt.title(f"{model_name} Confusion Matrix (Validation)")
    plt.ylabel('True Label')
    plt.xlabel('Predicted Label')
    plt.show()
    
    return model  # Return the fitted model for potential reuse
