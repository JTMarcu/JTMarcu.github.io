Shinkansen Passenger Satisfaction

Comprehensive data analysis and predictive modeling for passenger satisfaction on Japan's Shinkansen Bullet Train, revealing the key factors that drive a positive experience.

View Jupyter Notebook

Overview

Predicting Passenger Satisfaction

In this project, I leveraged a dataset combining travel information (class, delay times, distance) and survey feedback (comfort, cleanliness, onboard service, etc.). The goal was to predict whether a passenger was satisfied (1) or not (0) with their Shinkansen experience. By examining key features, my model highlights areas where operators can improve service to boost overall satisfaction.

  • Data sources: Traveldata_train/test.csv, Surveydata_train/test.csv
  • Merged on passenger ID for a complete 35,000+ record dataset
  • Features include seat comfort, onboard service, cleanliness, arrival delays, etc.
  • Target variable: Overall_Experience (binary: 1 = satisfied, 0 = not satisfied)

Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn, TensorFlow/Keras

Data Preparation & Feature Engineering

Cleaning & Transformations

Missing values were imputed using random sampling or KNN approaches, ensuring minimal data loss. Categorical features (e.g., Travel_Class, Gender) were label-encoded. For numeric ratings (1–5), we retained them as ordinal features. Delays were combined into a single “total delay” feature to capture overall on-time performance. Additional interaction features (like “Loyal_Business”) were tested for improved predictive power.

  • KNNImputer for missing data on survey responses
  • Label/One-Hot encoding for categorical features
  • Min-Max or Standard Scaling for numeric features (SVM, NN usage)
  • Interaction & derived features (e.g., total delay = departure + arrival delay)

Model Development

Ensemble Learning and Neural Networks

Multiple classification algorithms were tested: Random Forest, AdaBoost, Gradient Boosting, SVM, and a simple Neural Network. Stratified cross-validation (5-fold) validated each model’s accuracy, precision, recall, and F1-score. Hyperparameter tuning (GridSearchCV / RandomizedSearchCV) refined the ensemble methods:

  • Random Forest: ~93% accuracy
  • AdaBoost / Gradient Boosting: up to ~95% accuracy, top performer
  • SVM: ~90% accuracy (slower to train, lower performance)
  • Neural Network (MLP): ~92% accuracy with 2 hidden layers

AdaBoost and Gradient Boosting emerged as the best choices, achieving around 95% accuracy on validation sets. Feature importance analysis revealed seat comfort, onboard service, and punctuality as top predictors.

Insights

  • Seat comfort & onboard service are critical satisfaction drivers
  • Timeliness has a major impact; even small delays can sour the experience
  • Ensuring cleanliness and legroom are also key to passenger happiness
  • Opportunities to improve service in lower classes (Economy) to match higher-tier satisfaction rates
