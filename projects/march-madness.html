Built an end-to-end prediction system for the $50K Kaggle March Machine Learning Mania 2026 competition. Engineered 7+ advanced features from 16 seasons of NCAA data (2010–2025), trained an ensemble of XGBoost, LightGBM, and Logistic Regression models with spline-calibrated probabilities, and deployed an interactive bracket predictor with a FastAPI backend and real-time matchup explorer.

Overview

Predicting NCAA tournament outcomes is one of the most popular applied ML challenges—a 68-team single-elimination bracket with enormous variance. This project tackles the Kaggle March Machine Learning Mania 2026 competition, scored on Mean Squared Error (Brier score) of predicted win probabilities.

Key highlights of the 2026 system:

  • Processed 34 raw datasets covering both men's and women's tournaments (2010–2025)
  • Engineered 7 difference features per matchup: seed, point differential, offensive efficiency, win percentage, Elo rating, FG%, and FT%
  • Trained 3 model families (Logistic Regression, XGBoost, LightGBM) with separate men's/women's pipelines
  • Best ensemble achieves holdout MSE of 0.1571 (60% LR + 20% XGB + 20% LGBM)
  • Built interactive bracket predictor with FastAPI + Streamlit dashboards for real-time tracking
  • Generated 11 diverse Kaggle submissions ranging from simple baselines to tuned ensembles

Technologies: Python, XGBoost, LightGBM, Scikit-learn, Pandas, NumPy, Statsmodels, FastAPI, Streamlit

Feature Engineering

From Raw Box Scores to Predictive Features

Raw game data is converted into per-team, per-season statistics using a symmetric perspective-flipping approach—each game generates two rows (one from each team's perspective), enabling clean aggregation.

Model Development

Multi-Model Ensemble Strategy

Rather than relying on a single model, the system trains three complementary model families and blends their outputs:

Model Registry
ModelRoleConfiguration
Logistic RegressionStable baseline, well-calibrated probabilitiesC=0.25 (men), C=0.15 (women), StandardScaler
XGBoostNon-linear interactions, custom Cauchy lossdepth=2, n=200, γ=5, subsample=0.35
LightGBMEnsemble diversity, fast iterationTuned via RandomizedSearchCV

Key Modeling Decisions

  • Separate M/W models: Men's and women's tournaments have different dynamics; separate pipelines consistently outperformed combined training
  • Cauchy loss for XGBoost: Heavy-tailed loss function robust to blowout outliers in point differential regression
  • Spline calibration: UnivariateSpline maps raw point differential predictions to well-calibrated win probabilities via binned averaging
  • Prediction clipping: All probabilities clipped to [0.025, 0.975] to avoid extreme Brier score penalties

Validation Strategy

  • Time-based split: 2010–2024 training, 2025 holdout validation
  • Repeated 5-fold cross-validation (3 repeats) for XGBoost iteration tuning
  • Evaluated on MSE (Brier score), log loss, and accuracy

Key Insights

  • The 3-model ensemble consistently outperforms any single model
  • Adding FG% and FT% to the feature set improved MSE from baseline
  • Separate men's/women's pipelines with different regularization strengths outperform combined training
  • Logistic Regression contributes the most stable signal (60% weight in the best ensemble)
  • Spline calibration on XGBoost point-differential predictions reduces Brier score
