Live Data Visualizer

Real-time stock, weather, and news dashboard built with Streamlit and powered by the Model Context Protocol (MCP).

Sample Dashboards

Project Overview

The Live Data Visualizer is an interactive Streamlit dashboard that integrates stock price data, financial news headlines, and real-time weather updates into one unified interface. It auto-refreshes every 10–30 seconds and is ideal for analysts, developers, and business leaders who want contextual insights at a glance.

  • Live Stock Tracker: Real-time stock quotes with open price comparison and trend monitoring.
  • News Headlines: Yahoo Finance RSS feed parsing for up-to-the-minute headlines by stock symbol.
  • Weather Widget: Live city weather via OpenWeatherMap API including icon, temperature, and conditions.
  • Autorefresh Engine: Streamlit autorefresh module ensures a live experience without manual reloads.
  • MCP Integration: Communicates with local tools served via FastAPI under the Model Context Protocol (MCP).

Capabilities & Use Cases

  • Custom Symbols: Users can input any stock tickers (e.g., AAPL, TSLA, RIVN) for live monitoring.
  • City Weather Lookup: Instantly fetch weather for any global city name.
  • Auto-Updating UI: Dynamic layout with no reloads thanks to autorefresh and Streamlit layout APIs.
  • Local & Lightweight: Runs entirely on your local machine—ideal for privacy-sensitive contexts or offline analysis.
  • Extendable Architecture: Easily add new widgets like crypto prices, commodity trackers, or chat interfaces.

Technical Stack

  • Python 3.10
  • Streamlit & Altair
  • FastAPI + MCP server
  • YFinance, Feedparser
  • OpenWeatherMap API
  • Dotenv, Requests, Pandas

Challenges & Solutions

API Rate Limits

  • Implemented caching with `st.cache_data` to reduce unnecessary API calls.
  • Grouped API refresh intervals using a single autorefresh selector.

Dashboard Responsiveness

  • Used Streamlit columns to balance layout between stock data, weather, and headlines.
  • Mobile layout improved using responsive CSS for embedded screenshots and components.

Business Impact

  • Centralized multiple live data sources into a single, navigable dashboard.
  • Accelerated decision-making by surfacing actionable signals in one view.
  • Provided a foundation for internal analytics tools with minimal deployment overhead.
