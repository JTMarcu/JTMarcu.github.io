Live Data Visualizer

The Live Data Visualizer is a cutting-edge tool designed to empower businesses and individuals with real-time insights. By integrating with the Model Context Protocol (MCP), it fetches and visualizes live data streams, such as stock prices, enabling data-driven decision-making and actionable insights.

Why Use Live Data Visualizer?

In today's fast-paced world, staying ahead requires access to real-time data. The Live Data Visualizer provides businesses with the tools to:

  • Make Informed Decisions: Access live stock prices and other data streams to react quickly to market changes.
  • Enhance Operational Efficiency: Streamline workflows with a user-friendly dashboard and one-click setup.
  • Gain Competitive Advantage: Leverage real-time insights to identify trends and opportunities before competitors.

Key Features

  • Real-Time Data Visualization: Stream and display live data updates for immediate insights.
  • Stock Price Monitoring: Retrieve and visualize live stock prices for any symbol.
  • MCP Integration: Seamlessly connect with MCP servers to fetch contextual data.
  • Interactive Dashboard: Explore data through an intuitive and user-friendly interface.
  • Scalable Architecture: Modular design allows for easy customization and expansion.
  • One-Click Deployment: Launch the MCP server and dashboard with a single command.

Who Can Benefit?

  • Financial Analysts: Monitor stock prices and market trends in real time.
  • Business Owners: Gain insights into key metrics to make data-driven decisions.
  • Developers: Use the modular architecture to build custom data visualizations.
  • Educators: Demonstrate real-time data analysis techniques in classrooms or workshops.

Technologies Used

  • Frontend: Streamlit for interactive dashboards.
  • Backend: Python with FastAPI for API development.
  • Data Handling: Pandas for data manipulation.
  • MCP Integration: mcp-python-sdk for seamless client/server communication.

Getting Started

  1. Clone the Repository: 
    git clone https://github.com/JTMarcu/live-data-visualizer.git
cd live-data-visualizer
  2. Create a Virtual Environment: 
    python -m venv venv
.\venv\Scripts\activate
  3. Install Dependencies: 
    pip install -r requirements.txt
  4. Configure Environment Variables:

    Create a .env file (or copy from .env.example) and set your MCP server URL:

    MCP_SERVER_URL=http://localhost:8000

Quick Start

To launch the project, execute the following command:

python main.py
