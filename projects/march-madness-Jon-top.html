Overview

March Madness Prediction Model Using Machine Learning

Developed a predictive model to forecast NCAA basketball tournament outcomes using historical game data. This end-to-end solution leverages detailed box score statistics from both regular seasons and tournaments (2010-2024) to predict 2025 matchups. Key components:

  • Combined men's and women's basketball data (117,000+ games)
  • Engineered 12 advanced team statistics including offensive efficiency and scoring margin
  • Implemented Random Forest classifier with hyperparameter tuning
  • Achieved 0.753 AUC score and 67% accuracy in validation
  • Generated probabilistic predictions for 2025 tournament bracket

Technologies: Python, Scikit-learn, Pandas, NumPy, Seaborn

Data Preparation & Feature Engineering

Structured Multi-Source Basketball Data

Processed 4 distinct datasets containing 34 game metrics:

  • Aggregated team statistics across seasons using SQL-like operations
  • Created symmetrical features for both winners/losers using perspective flipping
  • Engineered advanced metrics:
"WinPct", "ScoreMargin", "OffEff = (Points/Possessions)*100", 
"DefEff", "ShootingPercentages", "ReboundDifferentials"

Implemented possessions calculation:

Possessions = FGA - OReb + TO + 0.44*FTA
  • Handled class imbalance through stratified sampling
  • Visualized key trends using Seaborn/Matplotlib (score distributions, seasonal trends)

Model Development

Optimized Random Forest Classifier

Built predictive pipeline using machine learning best practices:

  • RandomizedSearchCV for hyperparameter tuning (10 iterations, 5-fold CV)
  • Evaluated using probabilistic metrics: Brier Score, Log Loss
  • Feature importance analysis revealed key predictors:
    • Offensive Efficiency Difference (23%)
    • Win Percentage Differential (19%)
    • Scoring Margin Gap (15%)

Validation Strategy

  • Time-based split: 2010-2023 training, 2024 validation
  • Class-weighted evaluation to handle natural imbalance
  • Neutral court assumption for tournament predictions

Key Insights

  • Model shows strong calibration (Brier <0.2)
  • Handles close games effectively (64% accuracy on ≤5pt margins)
  • Women's tournament predictions slightly outperform men's (AUC 0.78 vs 0.72)
  • Offensive efficiency difference is strongest single predictor
