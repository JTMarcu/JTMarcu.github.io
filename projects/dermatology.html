Melanoma Cancer Image Classification

Deep learning project to classify high-resolution dermoscopic images of skin lesions as Benign or Malignant (Melanoma).

View Jupyter Notebook

Overview

This project applies deep learning and transfer learning to classify high-resolution dermoscopic images of skin lesions as either Benign or Malignant (Melanoma). Using a curated dataset of over 13,000 images from Kaggle, we trained a convolutional neural network to support early melanoma detection — a critical step in improving cancer outcomes through computer-aided diagnostics.

Technologies Used

  • PyTorch – for model building, training, and evaluation.
  • Torchvision – for dataset handling, image transforms, and pretrained models (ResNet18).
  • Scikit-learn – for evaluation metrics (classification report, confusion matrix).
  • Matplotlib & Seaborn – for data and result visualization.
  • Jupyter Notebook – for development and experimentation in an interactive environment.

Process

  • Data Loading: Structured image dataset organized into train and test folders by class (Benign vs Malignant).
  • Data Preprocessing: Images resized, normalized, and augmented for improved generalization.
  • Model Selection: Transfer learning using pretrained ResNet18, customized for binary classification.
  • Training: Initially trained only the final layer, then introduced weighted loss to penalize false negatives more heavily.
  • Evaluation: Assessed performance with accuracy, precision, recall, F1-score, and confusion matrix.
  • Visualization: Displayed correct and incorrect predictions for interpretability and analysis.

Challenges

  • Balancing sensitivity vs specificity in a medical context where false negatives are especially dangerous.
  • Training on CPU, which increased iteration time and required careful model design and efficiency tuning.
  • Handling real-world image variability through data augmentation and transfer learning fine-tuning.

Outcome

  • Achieved over 86% accuracy, with strong recall for benign and improved recall for malignant lesions using weighted loss.
  • Built a fully functioning image classification pipeline that can serve as a base for clinical decision support tools in dermatology.
  • Gained practical experience in model optimization, interpretability, and dataset preprocessing within a healthcare context.
