Melanoma Cancer Image Classification

Deep learning project to classify high-resolution dermoscopic images of skin lesions as Benign or Malignant (Melanoma).

View Jupyter Notebook

Overview

This project applies deep learning and transfer learning to classify high-resolution dermoscopic images of skin lesions as either Benign or Malignant (Melanoma). Using a curated dataset of over 13,000 images from Kaggle, we fine-tuned a convolutional neural network to support early melanoma detection — a critical step in improving cancer outcomes through computer-aided diagnostics. The final model achieved 94% accuracy and over 91% recall on malignant cases, demonstrating strong generalization and clinical relevance.

Technologies Used

  • PyTorch – for model building, training, and evaluation.
  • Torchvision – for dataset handling, image transforms, and pretrained ResNet18 model.
  • Scikit-learn – for classification reports, precision/recall/F1 metrics, and confusion matrix analysis.
  • Matplotlib & Seaborn – for visualizing sample predictions and performance metrics.
  • Jupyter Notebook – for experimentation, analysis, and iterative development.

Process

  • Data Loading: Structured dataset split into training and test folders with subdirectories for Benign and Malignant classes.
  • Data Preprocessing: Resized and normalized all images, with augmentation planned for future robustness improvements.
  • Model Selection: Applied transfer learning using ResNet18 pretrained on ImageNet; final layer customized for binary output.
  • Training: Started with the classifier head, then applied weighted loss to reduce false negatives, followed by fine-tuning of the final ResNet block.
  • Evaluation: Assessed model performance using accuracy, confusion matrix, and detailed classification metrics (precision, recall, F1-score).
  • Visualization: Displayed prediction examples and heatmaps to interpret model behavior and identify misclassifications.

Challenges

  • Reducing false negatives was critical for safety, requiring class weighting and architectural fine-tuning to favor malignant recall.
  • Initial CPU-only training added time constraints, requiring efficient model and data pipeline design.
  • Balancing recall and precision in a binary classification context with visually similar classes was a key modeling challenge.

Outcome

    • Achieved 94% overall accuracy with 91% recall and 93% F1-score on malignant cases — outperforming the baseline by a wide margin.
    • Built a clinically relevant image classification pipeline using real-world data, optimized through weighted loss and targeted fine-tuning.
    • Demonstrated ability to design, train, and evaluate deep learning models for high-stakes healthcare problems using PyTorch and open-source tools.
