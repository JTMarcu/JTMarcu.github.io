RAG Gandalf Chatbot

A "Lord of the Rings" expert chatbot built using LangChain and Hugging Face.

Overview

Gandalf is a fully local Retrieval-Augmented Generation (RAG) chatbot designed to answer questions about "The Lord of the Rings" using LangChain, FAISS, and the Mistral-7B-Instruct model. This project ensures privacy by running entirely on your local machine, with no external API calls after setup.

This project leverages Retrieval-Augmented Generation (RAG) techniques to create a chatbot that acts as a "Lord of the Rings" expert. By combining LangChain for orchestration, FAISS for vector search, and the Mistral-7B-Instruct model for local inference, Gandalf provides accurate and contextually relevant answers to user queries. The chatbot processes "The Lord of the Rings" PDF to build a knowledge base, ensuring privacy and efficiency by running entirely on your local machine.

Features

  • Local Execution: No internet or cloud APIs required after initial setup.
  • PDF Integration: Processes "The Lord of the Rings" PDF for question answering.
  • Vector Search: Uses FAISS for efficient document retrieval.
  • Mistral-7B-Instruct: Runs the lightweight mistral-7b-instruct-v0.1.Q4_K_M.gguf model locally.
  • Gradio Interface: User-friendly web interface for interacting with the chatbot.

Technologies Used

  • LangChain: For orchestration and document processing.
  • FAISS: For efficient vector-based document retrieval.
  • Mistral-7B-Instruct: Lightweight local model for generating answers.
  • Gradio: For building an interactive web interface.
  • Python: Core programming language for the project.

Challenges

One of the key challenges was integrating multiple components, such as LangChain, FAISS, and the Mistral model, into a seamless pipeline. Ensuring the chatbot could run entirely locally without relying on external APIs required careful optimization of the model and vector search. Additionally, processing large PDFs and splitting them into meaningful chunks for embedding posed a challenge in terms of memory and computational efficiency.

Outcome

The Gandalf chatbot successfully provides detailed and accurate answers to questions about "The Lord of the Rings" universe. By leveraging RAG techniques, it demonstrates the potential of local AI solutions for privacy-focused applications. The project also highlights the effectiveness of lightweight models like Mistral-7B-Instruct for running inference on personal devices.

How It Works

  1. Document Processing: The PDF is split into chunks using LangChain's text splitter.
  2. Vector Embedding: Each chunk is embedded using sentence-transformers/all-MiniLM-L6-v2 and stored in a FAISS index.
  3. Question Answering: The Mistral-7B-Instruct model retrieves relevant chunks and generates answers.
