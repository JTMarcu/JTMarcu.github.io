Gandalf: A Middle-earth Chatbot

A Tolkien-themed expert chatbot built using LangChain, FAISS, and the Mistral-7B-Instruct model, deployed via Gradio on Hugging Face Spaces.

Overview

Ask Gandalf the Grey anything! This chatbot is trained on the full texts of The Hobbit, The Lord of the Rings, and The Silmarillion to respond with wisdom (or wit) drawn from Tolkien's legendarium.

Built with LangChain and a FAISS vector database, the chatbot retrieves relevant context and uses the mistralai/Mistral-7B-Instruct model for generation. The Gradio interface is hosted live via Hugging Face Spaces, enabling anyone to seek counsel from the Grey Wizard himself.

Features

  • Retrieval-Augmented Generation: Combines traditional search with neural text generation for accurate responses.
  • Multi-book Indexing: Incorporates The Hobbit, LotR, and The Silmarillion PDFs.
  • Custom Metadata: Displays source chapter and book for each answer.
  • Gandalf-style Fallback: When no answer is found, the model responds with wizardly flair.
  • Hosted UI: Powered by Gradio and live on Hugging Face Spaces.

Technologies Used

  • LangChain: RAG pipeline and orchestration
  • FAISS: For fast vector-based document retrieval
  • Sentence Transformers: all-MiniLM-L6-v2 for chunk embeddings
  • Mistral-7B-Instruct: Hosted via Hugging Face Inference API
  • Gradio: Interactive frontend
  • Python: Core programming language

Challenges

A key challenge was parsing and chunking large PDFs in a way that preserved semantic meaning and chapter boundaries. Integrating metadata (book, chapter name) into each vector entry was essential for meaningful context and traceability. Deployment also required optimizing the interface for a Hugging Face-hosted environment.

How It Works

  1. Chapter Detection: Each book PDF is split into chunks with chapter metadata via custom LangChain logic.
  2. Embeddings: Each chunk is embedded with sentence-transformers/all-MiniLM-L6-v2 and stored in a FAISS index.
  3. Answer Generation: Relevant chunks are retrieved and passed to the Mistral-7B-Instruct model to generate a response.

Future Enhancements

  • Support for audio questions and TTS Gandalf voice responses.
  • Integration with additional texts like Unfinished Tales and HoMe volumes.
  • Enhanced document viewer to show original text alongside answers.
