Gandalf: Tolkien Lore RAG Chatbot 🧙

A Retrieval-Augmented Generation chatbot grounded in J.R.R. Tolkien's core legendarium — combining semantic vector search over the full text with the Qwen2.5-7B-Instruct LLM to deliver canonical, chapter-referenced answers in Gandalf's voice.

Live Demo Source Code

Overview

Gandalf is a Retrieval-Augmented Generation (RAG) chatbot grounded in J.R.R. Tolkien's core legendarium:

  • 📘 The Hobbit (1937)
  • 📗 The Lord of the Rings (1954–1955)
  • 📙 The Silmarillion (1977)

It searches across all three books simultaneously via FAISS vector search, retrieves the most relevant text chunks with book/chapter metadata, and feeds them to Qwen2.5-7B-Instruct via the HuggingFace Inference API to generate in-character, citation-backed answers.

Key Features

  • Multi-Book RAG: Searches across all three books simultaneously via FAISS for comprehensive answers.
  • Source Citations: Every answer includes the book name and chapter reference from the retrieved context.
  • Gandalf Persona: Responds with ancient wisdom, poetic cadence, and occasional wit — fully in character.
  • Graceful Fallbacks: When the model can't find an answer, it returns an in-character Gandalf quote instead.
  • Middle-earth Themed UI: Dark parchment theme with Cinzel & Crimson Text fonts and gold accents.
  • Auto-Deploy CI/CD: Push to main → GitHub Action syncs to HuggingFace Spaces automatically.

Tech Stack

  • Embeddings: sentence-transformers/all-MiniLM-L6-v2
  • Vector Store: FAISS (via langchain-community)
  • LLM: Qwen/Qwen2.5-7B-Instruct via HuggingFace Inference API (chat_completion())
  • Web UI: Gradio 5 Blocks API with a custom gr.themes.Base Middle-earth theme
  • PDF Parsing: pdfminer.six via LangChain's PyPDFLoader
  • Orchestration: LangChain RAG pipeline
  • CI/CD: GitHub Actions → huggingface_hub.upload_folder() auto-deploy
  • Language: Python 3.10+

How It Works

  1. Embed the Question: The user's query is vectorized with all-MiniLM-L6-v2.
  2. Retrieve Context: FAISS returns the most relevant text chunks (500 chars each) with book/chapter metadata.
  3. Generate Answer: The context + question are sent to Qwen2.5-7B-Instruct via InferenceClient.chat_completion() with a Gandalf persona system prompt.
  4. Cite Sources: The response includes the book name and chapter from the top retrieved chunk.
  5. Fallback: If the model says "I don't know", a random in-character Gandalf quote is returned instead.

Challenges & Solutions

  • PDF Chunking with Metadata: Parsing and splitting large PDFs while preserving semantic meaning and chapter boundaries required custom LangChain logic to embed book/chapter metadata into each vector entry.
  • Model Selection: Iterated from Mistral-7B-Instruct to Qwen2.5-7B-Instruct for improved response quality, better instruction following, and more consistent English-only output.
  • Deployment Optimization: Configured CI/CD with GitHub Actions to auto-sync only essential files to HuggingFace Spaces, keeping the deployment lean.
  • Persona Consistency: Careful prompt engineering ensures Gandalf stays in character — responding only in English with poetic cadence, even for edge-case queries.
