Built a production SaaS platform from concept to launch in 5 months as Co-Founder & CTO. Full-stack development using modern tech: Next.js 16, React 19, FastAPI, and PostgreSQL with 42-table architecture. Demonstrates end-to-end product development, deployment, and cloud infrastructure expertise.

What I Built

A production SaaS platform for workplace culture assessment and B Corp certification. Companies use HiveWell to evaluate their organizational culture, receive detailed analytics, and generate stakeholder reports.

My Role: Solo full-stack developer - architected, built, and deployed the entire platform in 10 months.

Tech Stack

Frontend

  • Next.js 16 - App Router, Server Components
  • React 19 - Modern UI framework
  • TypeScript 5 - Type-safe development
  • Tailwind CSS - Utility-first styling
  • Zustand - State management
  • Recharts - Data visualization

Backend

  • FastAPI - High-performance Python API
  • Python 3.11 - Async/await patterns
  • Pydantic - Data validation
  • JWT - Authentication & authorization
  • ReportLab - PDF generation
  • Resend API - Email delivery

Infrastructure

  • PostgreSQL 14 - 42-table relational database
  • Railway - Backend hosting (Docker)
  • Vercel - Frontend hosting (CDN)
  • Docker - Container orchestration
  • GitHub - Version control & CI/CD

Key Features

  • Multi-Role Assessment System: 164-question evaluation engine across 8 different organizational roles
  • Real-Time Analytics Dashboard: Interactive charts and data visualization with live updates
  • Automated PDF Reports: Stakeholder reports generated and delivered automatically (100% success rate)
  • Admin Panel: Complete management system for users, organizations, and assessments
  • 42-Table Database: Complex PostgreSQL schema handling organizational hierarchies and assessment data
