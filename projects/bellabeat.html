Bellabeat Smart Device Usage Analysis

Analysis of Fitbit user data to uncover health behavior patterns and provide actionable insights for Bellabeat's product development and marketing strategies.

Overview

This analysis examined fitness tracker data from 30 Fitbit users to understand patterns in physical activity, sleep, and health metrics. The goal was to identify opportunities for Bellabeat to improve their women's health products and marketing strategies.

Technologies Used

  • R Programming
  • Tidyverse (dplyr, ggplot2)
  • Janitor for data cleaning
  • reshape2 & corrplot for data visualization
  • Kaggle Data Platform

Challenges

Key challenges included merging datasets from different time periods, handling inconsistent sleep monitoring data, and working with limitations of the sample size (only 30 users). Special handling was required for heart rate data measured every 5 seconds and weight logs with missing values.

Outcome

Analysis revealed significant correlations between activity intensity and calorie burn (+0.79), and between sleep duration and reduced sedentary time. Key recommendations included:

  • Implement personalized activity goal setting features
  • Develop intelligent movement reminders for sedentary users
  • Enhance sleep tracking with stress management insights
  • Create social features for community motivation
