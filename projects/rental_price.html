Rental Price Optimization Tool

A tool that uses scraped data from apartments.com to analyze rental prices in the San Diego area, helping property managers optimize their pricing strategies.

View Jupyter Notebook

Overview

This project scrapes rental data from apartments.com using Python tools like Selenium and BeautifulSoup. The data is cleaned and analyzed to provide insights into rental trends in the San Diego area. Dashboards are created in Power BI and Tableau to visualize the data and assist property managers in making informed decisions.

  • Scraped data includes property details, prices, square footage, and more.
  • Data cleaning ensures accurate and usable datasets.
  • Dashboards provide visual insights into rental trends and pricing strategies.
