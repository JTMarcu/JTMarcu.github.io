Rental Price Optimization Tool

A tool that leverages scraped Apartments.com data, deep rental analysis, and interactive dashboards to help property managers optimize rates and maximize revenue.

View Jupyter Notebook

Project Overview

Problem Statement

Property managers need to set competitive rents without underpricing or losing revenue. This project collects, cleans, and analyzes rental listings to answer:

  • What is the distribution of rents across San Diego County?
  • How does unit size (SqFt) correlate with price?
  • Which amenities command higher premiums?
  • Where are the most expensive and affordable areas by ZIP code?
  • Can basic features predict rent prices accurately?

Methodology

We built a Selenium + BeautifulSoup scraper to extract unit-level data from Apartments.com, cleaned the dataset using Pandas, and performed detailed analysis inside Jupyter Notebook:

  • Explored price distributions and outliers
  • Analyzed rent impact by bedrooms, amenities, and location
  • Modeled basic rent predictions using linear regression
  • Prepared interactive dashboards in Tableau and Power BI

Key Findings

Snapshot Insights

  • Median Rent: ~$2,870; Average Rent: ~$3,025
  • Median Price per SqFt: ~$3.46 (Avg ~$3.62)
  • Top Zip Codes by Avg Rent: 92130 (Carmel Valley), 92118 (Coronado), 92011 (Carlsbad)
  • Bedrooms vs Rent: Adding a bedroom increases rent ~$400–$600/month
  • Amenity Premiums: Washer/Dryer (+$340), Pet-Friendly (+$315), Pool (+$150), Air Conditioning (+$115)
  • Pet Friendliness: 95% of listings allowed pets
  • Prediction Model: Basic model achieved R² of 0.45 with ~$370 average prediction error

Technical Stack

  • Python 3.10+ Core language for orchestrating scraping, data cleaning, exploratory analysis, and modeling.
  • Selenium & BeautifulSoup Browser automation and HTML parsing for Apartments.com listings and unit-level details.
  • Pandas & NumPy Data cleaning, transformation, and metric calculations (e.g., PricePerSqFt, Amenity Premiums).
  • Regex & Logging Regex for extracting numeric values; logging for robust debugging and runtime tracking.
  • Scikit-Learn Linear regression model to predict rental prices from bedrooms, baths, sqft, and amenities.
  • Tableau & Power BI Interactive dashboards visualizing rent distributions, trends by city, zip code, and amenities.
  • Jupyter Notebook Exploratory analysis environment for dynamic coding, visualizations, and final report generation.

Challenges & Solutions

Dynamic Rendering

  • Listings and unit details load dynamically; solved with Selenium waits and custom timeouts.

Inconsistent HTML Structures

  • Variable amenity layouts handled via fallback scraping logic and selector hierarchies.

Data Normalization

  • Free-form rent, SqFt, and amenity text cleaned using regular expressions and regex parsers.

Business Impact

  • Generated over 13,000 detailed unit records covering San Diego County.
  • Identified rent premiums for key amenities and pet policies.
  • Surface geographic rental trends by ZIP Code and neighborhood.
  • Created predictive models to forecast rent ranges based on unit characteristics.

Next Steps

  • Rewrite Scraper with Playwright & Asyncio Move to async scraping for faster, concurrent page loading and extraction.
  • Enrich Listings with Geolocation Data Append latitude/longitude and visualize rent heatmaps across the county.
  • Expand Feature Engineering Incorporate property year built, walk score, and proximity to coastline into predictive models.
  • Build Historical Rent Archive Snapshot and store listings daily/weekly to model rent trends over time and forecast pricing shifts.
