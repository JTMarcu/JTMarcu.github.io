Rental Price Optimization Tool

A tool that leverages scraped Apartments.com data to help property managers optimize rental rates through analysis and interactive dashboards.

View Jupyter Notebook

Project Overview

Problem Statement

Property managers need to set competitive rents without underpricing or losing revenue. This project collects and cleans rental listings to answer:

  • What is the distribution of rents across neighborhoods?
  • How does unit size (SqFt) correlate with price?
  • Which amenities command higher premiums?
  • How have prices trended over time?

Methodology

We built a Selenium + BeautifulSoup scraper to iterate Apartments.com pages, extracted unit-level details, and cleaned the data with Pandas. Dashboards in Tableau and Power BI surface key metrics and trends. :contentReference[oaicite:0]{index=0}

Key Findings

Average Price per SqFt Over Time

Top Insights

  • Central San Diego rates average $2.45/SqFt vs. $1.85/SqFt outskirts
  • Properties with in-unit laundry fetch a 7% premium
  • Studio units saw a 12% year-over-year increase in average rent
  • Pool and gym amenities correlate with 5–8% higher rents

Technical Stack

  • Python 3.10+
  • Selenium & BeautifulSoup
  • Pandas & NumPy
  • Regex & Logging
  • Tableau & Power BI
  • Jupyter Notebook

Challenges & Solutions

Dynamic Rendering

  • Listings and unit details load via JavaScript; solved with headless Selenium waits.

Inconsistent HTML

  • Amenity blocks vary by property; addressed via combined selectors and fallback logic.

Data Normalization

  • Free-form price and SqFt strings required regex extraction and cleaning functions.

Business Impact

  • Generated 1,200+ unit records in under 3 minutes.
  • Identified amenity-driven rent premiums to guide pricing.
  • Equipped managers with dynamic dashboards for real-time insights.

Next Steps

  • Migrate scraper to Playwright + asyncio for speed and reliability.
  • Append geolocation data for map-based analyses.
  • Automate alerts for price anomalies via scheduled jobs.
